# CLAUDE.md — working on homebrew-tap

The Homebrew tap for [say-hi](https://github.com/ivylikethevine/say-hi).

- `Formula/say-hi.rb` is generated by say-hi's release workflow from
  `packaging/homebrew/say-hi.rb`, which opens a PR here per release. Make
  formula changes there; an edit here is overwritten by the next release.
- CI (`.github/workflows/ci.yml`) runs `brew style`, `brew audit --strict
--online`, `brew install --build-from-source`, `brew test`, and
  `brew uninstall` on macOS and Linux, and a `lint` job: shellcheck over the
  scripts, actionlint, `.github/scripts/lint_workflows.sh` and zizmor over the
  workflows, with the tools pinned in `.github/actions/setup-tool/tools.txt`.
  The brew jobs wait on `lint`, and run only when the formula, a `*.sh` or
  `ci.yml` changed, or on a dispatch.
- `.github/workflows/drift.yml` runs weekly: `.github/scripts/formula_drift.sh`
  compares the formula's `url` version with say-hi's latest release, and a
  mismatch upserts one `formula-drift` issue via
  `.github/actions/upsert-tracking-issue` or, while
  issues are disabled here, fails the run.
- Workflow `uses:` are SHA-pinned with a version comment, with
  `contents: read` permissions (drift.yml's and tool-versions.yml's jobs add
  `issues: write`), and every job starts with `step-security/harden-runner`,
  in audit mode except tool-versions.yml's block.
- `.github/workflows/tool-versions.yml` runs weekly:
  `.github/scripts/check_tool_versions.sh` reports each action SHA and
  `tools.txt` pin behind upstream in one tracking issue. Dependabot opens no version-update PR; every
  bump is a hand edit.
- `docs/tapes/demo.tape` renders the README's `docs/tapes/demo.gif` on the containers
  `docs/tapes/fixtures.sh` brings up; the render is a hand step.
- PRs are squash-merged.
