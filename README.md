# `say-hi` on Homebrew

This repo exists to house the homebrew tap for my project, [say-hi](https://github.com/ivylikethevine/say-hi).

The documentation for that project is also available at the [github pages site here](https://ivylikethevine.github.io/say-hi/).

> Please read the docs for that project for more information, as _this repo is
> purely for packaging and installation_.

## Installation

```sh
brew install ivylikethevine/tap/say-hi
```
